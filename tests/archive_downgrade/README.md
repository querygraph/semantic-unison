# Archive round trip through an older Unison

Run with a current successful build receipt and an independently selected
unmodified baseline:

```sh
python3 tests/archive_downgrade/run.py \
  --build-receipt /absolute/current-build-RESULT.json \
  --baseline /absolute/older/unison \
  --report /private/tmp/new-archive-roundtrip.json
```

The runner verifies every current production source input and binary before
using fresh private synthetic roots. It uses identical root identities, hostname,
transport and two state directories throughout; archives are neither deleted nor
regenerated by the test. Current-only preferences are removed for baseline calls.
No SDK, photograph, catalog, Photo volume or production archive is used.

Ten stages exercise current compact-base merge, an old-peer no-op and one-sided
update, reopening with current Unison, conservative refusal of a merge whose
common version was written by the old binary, and recovery after an explicit
new current-version common synchronization. Both edits must survive missing-base
refusal. The test explicitly restores its known synthetic common version to
start recovery; the implementation never guesses one from conflicting edits.
The final disjoint merge and no-op must converge exactly.

The baseline no-op preserves receiver inode/bytes and archive names. Normal
archive bookkeeping can rewrite archive bytes; their hashes are retained before
and after rather than required to remain identical. Compatibility with the tested
baseline is not compatibility with all historical versions, optional archive
features, platforms or GUI configurations.
