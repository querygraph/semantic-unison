These tests qualify the new org.firstpair.dng-xmp/1 container locator and its
existing exact semantic transfer contract. They currently run on macOS and
require the private synthetic fixture directory to be on APFS. Production
BigTIFF parsing remains portable; this is no Windows or Linux runtime claim.

Run each native compiler independently:

    python3 tests/dng_profile_v1/run.py --ocamlopt /usr/local/bin/ocamlopt --keep-work --receipt /private/tmp/dng-v1-stock.json
    python3 tests/dng_profile_v1/run.py --ocamlopt /Users/alexy/.opam/5.2.0+ox/bin/ocamlopt --keep-work --receipt /private/tmp/dng-v1-ox.json

fixtures.py produces synthetic classic TIFF, BigTIFF, and embedded CR camera
profile containers with fixed recorded placement. Outer and profile byte
orders vary independently. The fixture producer records the headers,
directory tables, counted values, pointer lists, strip/tile/JPEG preview
extents, original-file data, opcodes and profile values that must stay outside
XMP. These records are the expected-range oracle; no second TIFF parser or
production locator discovers the expected ranges.

The ML harness uses public direct and wrapper inspectors, checks the unchanged
classic /0 eligibility, and compares canonical SDR/0 and SDE/0 bytes against
the existing independent Python wire reference. Changed metadata is applied
with both the explicit extension and the registry, and an unchanged update
makes zero data writes. Safe opaque payload and inline value mutations must
remain Other_bytes and ineligible for a metadata plan. Bytes outside any
declared TIFF extent also remain protected by the complete complement proof.
Cross-version proof and response binding remain distinct.

Malformed fixtures cover unsigned64 limits, count/product/extent bounds,
BigTIFF layout, unsupported pointer/value types, repeated/cyclic graphs,
duplicate tags, embedded CR type/layout/count/chain rules and XMP aliases of
independently placed protected ranges. A finite cancellation-check budget and
subprocess timeout bound the test workload; they do not establish a process
RSS limit. The payloads are arbitrary synthetic bytes, not valid images,
rendering controls or an Adobe validation oracle.

Four real sparse files have a primary IFD or XMP packet beyond 4GiB in both
byte orders. Only public inspection and exact packet reads run on them.
Their logical and allocated sizes and bounded known-address bytes are
retained; their holes are never fully hashed or materialized.

Three private source variants must fail designated actual assertions:
discarding the CR relative value base rejects a valid profile; omitting CR
counted-value protection admits an XMP alias; and widening the CR tag/type
grammar to admit a prohibited nonzero Exif-pointer field whose target is XMP.
The production source and API contain no test hooks.

The runner builds outside the checkout and records source/compiler hashes,
exact commands, logs, generated bytes, independent placement/wire oracles and
the complete retained artifact inventory. Pass --keep-work for review;
without it the receipt records that its private artifact directory was
deleted. No Photo, Lightroom, catalog/cache, production file or Adobe SDK
invocation is part of this suite.
