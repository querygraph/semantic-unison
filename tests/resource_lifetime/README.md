# Native retained-resource lifecycle

Use an immutable, compiler-matched Make snapshot:

```sh
python3 tests/resource_lifetime/run.py --build /absolute/private/build --ocamlopt /absolute/compiler/ocamlopt --keep --receipt /private/tmp/lifetime.json
```

The actual linked TargetBinding, FinalPublication, runtime and resource gate
operate on private synthetic files. A native `/dev/fd` census excludes its own
enumeration descriptor. Six original groups / 37 assertions observe prepared
four-FD and finalized five-FD ownership, minimum-budget Source progress, serial
validation borrowing, deferred release, legacy handoff, failures and exact retry.
Two further groups / 21 assertions privately fail the Runtime success continuation
after native preparation, for immediate and genuinely queued grants. Both must
preserve the original exception, close native ownership before retiring credits,
and complete an admitted retry.

Three private source regressions produce four designated rejections: premature
producer-return retirement, nested Consumer validation acquisition, and the old
reservation-only cleanup after immediate/asynchronous token-return failure.
The runner reuses original interfaces and recompiles dependent native objects in
order; completed fixtures, variants, objects, binaries and receipts remain when
`--keep` is selected. Production has no fault switches.

This observes phase boundaries, not hidden native allocation peaks or all legacy
families. It establishes no whole-process FD/RSS cap, physical APFS sharing,
performance gain, Adobe validation or photographic-corpus qualification.
`qualification-20261013.json` binds both final compiler snapshots and all controls.
