parent component is opened relative to the retained root with NOFOLLOW and checked
private ownership/mode. Bounded file reads/writes validate type, owner, single link,
name binding and epochs; declared append logs allow growth only. Creates and text
IO are bounded, UTF8 and private. Bare file contexts and undeclared rename/link
mutations refuse. Class setup occurs before acquiring the root descriptor.

## Independent parent replay

`recipes.py` is now the single pure source for generated helper/launcher
scripts, exact endpoint flags/options, per-phase intents and proxy scripts, so
the worker Session and the parent derive identical bytes. `parent.py` replays
every attempted call from its own pinned INTENT/CONFIG/PAIR/AUDIT (and
CANCELLATION) records: contiguous global numbering in original case order,
intent equal to the recipe phase, proxy configuration bound to the actual worker
PID and nine inherited resource identities, reproducible proxy script, and
re-running the normal/cancellation/producer auditor against raw frames. Final
fake-helper/copy/merge counter streams are sliced between consecutive intents
by `parent_counters.py`, so no counter can appear or vanish. Case START/RESULT/
FAILED and root ACCEPTED histories must match. A complete run must reach
exactly 69CLI/54fake/9copy/7merge/4producer/2cancellation; a failed prefix
must stop at the named case. The replay never proves worker settlement, parent
terminal or release.

## Owned entry, freezer and admission

`freeze.py` writes one PLAN/REQUEST/INDEX per compiler under
`doc/current-named-receiving-<compiler>-*`: original 21 rows and limits, the
pinned legacy source, every execution and production source, and the build
receipt naming the binary (used as both client and server). `metadata.py`
re-authenticates all of it without opening executables. `admission.py` checks
one fresh admission bound to that plan, command, compiler and deadline.

`entry.py --check-plan` is metadata only. Owner mode (`owner.py`) consumes the
workspace with mkdir, takes EXglobal IO then CPU00..07, hashes executables,
starts the worker, waits, and calls `parent_runtime.audit`. That binds the
worker terminal, inherited grant, WORKER-BINDING and WORKER-CLOSED records, then
replays every call through `parent_io.Reader`. Only then are CPU and IO
closed. A settled failed prefix closes and exits 1; any unknown state retains
every lease, child and directory and exits through the retained diagnostic.

`inventory_test.py` checks that every first-party module the run imports is
pinned; only two uncalled generic dispatcher functions are excluded.
