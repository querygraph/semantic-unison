# One current shared-budget cached-worker experiment

This is a finite host-local qualification controller, not a production transfer
entry point or an Adobe/Photo grant. `prepare.py` freezes current source and
compiler-matched objects without creating a workspace, lock or admission. The
parent entry requires a fresh exact Root admission and unused workspace. The
shared dispatcher rechecks it before launch, acquires existing EXglobal IO then
Unison00..07 without partial-set waiting, and passes those nine descriptors to
the worker. The worker checks actual parent/worker/command/inode metadata and
passes the same descriptors to every compiler and native sample child.

The fixed matrix is stock/Ox × workers1/2/4/6, one warmup and five measured
repetitions, six digests of one generated32MiB file per batch:48 native batches,
288 digests and9GiB requested primary logical reads. Six worker credits plus
two owner credits fit standing8; no Photo token or18-credit borrowing occurs.
The16GiB IO budget is declared planning, not a physical counter or hard limit.

The native primary-reader observer reports delivered bytes/chunks and checks
every digest, full input size, empty worker/CPU state and final descriptor count.
Wall/process-CPU intervals cover worker/read/hash/owner completion, not compiler
time, fixture creation or pool startup/shutdown. RSS is process-lifetime high
water; descriptor observations sample input opens and can miss transient peaks.
These are neither OS hard caps nor physical storage/network measurements.
The cached workload is not end-to-end synchronization, camera decoding or an
OxCaml-specific speedup claim. Shared activity prevents an absolute quiet claim.

All samples and original raw numeric output are retained. The parent reconstructs
the exact schedule and derived metrics, verifies current objects/compilers and
new measured executables, then requires actual worker/group settlement before
closing CPU and IO descriptors. An incomplete prefix remains failed. A live
worker after300s observation retains ownership; no broad timer kill or retry
is authorized. The individual private native sample has an explicit30s timeout.
No SDK, Adobe, original/camera file, UI, Main, cache publication or receiving
operation is in this contract. HOME/TMPDIR are private workspace paths, which
is environmental isolation rather than a sandbox. Toolchain/OS libraries remain
trusted; this is not a hermetic system attestation.

Source controls exercise numeric/refusal/uncertain-close paths, actual fake
compiler descriptor inheritance, disposable parent control flow and unchanged
shared target boundaries. Real stock/Ox probes also passed two64B reader controls.
Those are not the bulk matrix or new canonical runtime qualification. See
`doc/cached-worker-benchmark-request-v1.json` and the source qualification for
current pins. Execute only after the exact proposed admission is actually
published, fresh and independently revalidated. Never infer permission from
these files or another slot's release.
