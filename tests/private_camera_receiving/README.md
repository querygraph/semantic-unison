# Camera-derived receiving control: prepared kernel only

`case.py` is not an executor, native clone implementation, or grant. Importing
it reads no input. There is no camera path default or standalone payload command.
[Seven actual tiny-fixture/mock controls](../qualification/camera-receiving-case-source-controls-actual-20261016.json)
passed under canonical Unison8, with actual outer terminal/group/token closure.
They do not use Unison, Adobe, a camera file, or EXglobal IO.

The next separately reviewed owner must provide all of the following before
this kernel can be used with the retained Unison-owned camera-derived clone:

1. Exact one-use source/admission/command/interpreter/artifact pins, source native
   epoch and historical SHA ancestry, unused private workspace, declared logical
   read/write budget, and bounded start/call/observation deadlines.
2. Existing EXglobal then Unison00..07 acquisition and partial rollback, inherited
   FD identity checks, actual group/server/pump settlement, and unknown retention.
3. One native clone-only sender with distinct inode inside that workspace.
   No full-copy fallback, hardlinks, original/Photo source reads, borrowed-input
   chmod/write/rename/unlink, or fresh borrowed-source SHA. Verify SHA only on
   the disposable clone; fence the borrowed source by metadata before/after.
4. A pinned `invoke` hook that records intent before every call, persists its
   returned outcome before verification, audits independent session groups, and
   selects the intended ordinary receiver-basis fallback. Observe its debug
   evidence explicitly; do not infer fallback merely from exact output bytes.
5. A persistent `save` hook and failure recovery that separates known nonzero
   settlement from functional success and never releases on absent processes or
   an observation timeout alone.

The case starts with the verified mutable sender and empty receiver. It seeds,
holds an old receiver FD, appends a bounded original synthetic trailer to the
sender, updates, and checks exact full-byte output/old-reader preservation and
an unchanged no-op epoch. It must not silently patch unknown private metadata.
Appending a trailer tests generic exact fallback; it is not a claim of valid
camera encoding, semantic editing, private-reference closure, Adobe validation,
decoded samples, or rendering equivalence. The full SOL.md corpus and optional
SDK receiving requirements remain open after any one such future control.

No payload execution plan or admission is issued by this directory. Retained
camera-copy ancestry is not consent to read it again. Future cross-compiler
cases and their aggregate IO budget must be fixed in a fresh reviewed plan.
