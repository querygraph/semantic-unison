# Worker/owner FFI boundary controls

`run.py --build-result <current Ox Make RESULT.json> --report <fresh path>`
compiles three original probes against actual compiler-matched interfaces.
Private hashing is accepted; cache-parent acquisition and record-publication
availability are rejected at their exact named nonportable API. No generated
program is linked or run, so the negative source's path is never opened.
Use the standing shared CPU owner, at most one compiler job.

[Actual evidence](../qualification/worker-ffi-owner-boundary-actual-20261018.json)
records exact compiler/interface/source/log hashes. The accepted probe still
prints the installed scheduler warning; no alert is suppressed. This narrow
compiler boundary is not a complete reachable-C audit, runtime thread-safety
proof, third-party provider audit or platform/native execution qualification.
