# Generated-input receiving comparison preparation

`plan.py` constructs a fixed source-only comparison: stock/Ox, one versus three
workers on each endpoint, one warmup and five measured repetitions for each of
four configurations. Each fresh seed would contain the two previously qualified
generated DNG inputs and two reference single-thread SDK helpers. This gives
24 CLI calls/48 SDK helpers maximum, not permission to run them.

Every row reserves the same Unison00..07 eight-credit set, with endpoint work
configured as1+1 or3+3 plus two owner credits. Physical IO remains the existing
exclusive-global barrier. No18-credit exception, Photo/Classic operation,
source-camera access or prior-admission reuse is part of this preparation.
Configuration order rotates each round; exact order and every raw sample must
remain in the report. This does not control caches or other-machine activity.

This is end-to-end receiving-validation comparison, including hashing, transfer,
staging and scheduling. It does not isolate SDK decode throughput. Five samples
permit a descriptive median/range, not confident population tails or a universal
speedup claim. Declared32GiB logical IO is a conservative planning amount, not
an instrumented/enforced physical limit.

[Three pure planning controls](../qualification/sdk-throughput-plan-source-actual-20261016.json)
passed with the outer Unison8 closed. Runtime dispatcher, exact input/build/source
pins, per-row lifecycle and independent audit integration are still pending.
Fresh source review and separate IO/SDK scheduling admission are required before
execution. The actual multi-file V1 grant is consumed and cannot authorize this.

`transport.py` reuses the qualified one-shot transport, artifact/source hash
checks and intent/outcome persistence. It independently reconstructs each finite
row before binding its command, both endpoint flags and journal worker count.
The legacy transport's fixed workers3 identity is explicitly checked then
adapted to the row's exact1/3 setting; a changed identity is refused, not silently
normalized. Input rows are copied before use. [Nine source controls](../qualification/sdk-throughput-transport-source-actual-20261016.json)
cover the schedule, adapter, mutation refusal and old-target regressions. Calls
and outcomes are injected; there is no native execution or runtime admission.
Independent per-row/case/whole-prefix audit and actual child-boundary integration
remain required before freezing a request.
