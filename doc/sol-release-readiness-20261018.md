## Hard limits and measurement are still open

[Per-endpoint FD enforcement](endpoint-resource-enforcement.md) has actual96FD
stock/Ox CLI/selftest evidence. It is optional and per-process, not one shared
whole-tree96FD allowance. A positive hard-RSS request currently refuses125 before
target entry; RSS is not implemented. The unprivileged Darwin self-footprint
probe refused. Allocator callbacks, payload estimates, RLIMIT_AS and sampled RSS
are not substitutes. Supported containment/capability work remains substantive.

[Raw body accounting](rpc-body-input-lifetimes.md) declares512MiB in separate
request/reply lanes plus16MiB header/startup allowance, with a bounded-command
subset. These are payload/lifetime policies, not complete process heap budgets.
[Caller-owned decoder hooks](decoded-allocation-accounting-hooks.md) now admit
selected allocation charges before allocation, with 78 checks and two mutation
participants per compiler. Scoped RPC arguments are decoded once and shared
between scope and handler. Regular server arguments, both ordinary and bounded, now have independent
aggregate slots/selected bytes/elements, held through actual scope/handler and
queued output, with explicit value roots on typed/classifier uncertainty. These
mechanisms do not bound arbitrary decoded lifetimes: client results, custom
stream inputs, conversion/global escapes, metadata/outbound buffers and other baseline
families still require accounting. See the [regular request owner evidence](../tests/qualification/rpc-legacy-decoded-owner-actual-20261018.json)
for exact current controlled/build scope. [Inventoryv13](owned-resource-remaining-inventory-20261018-v13.json)
retains the precise earlier ownership/platform findings.

The saved warm32MiB repeated matrix is historical and not a current performance
run. Its semantic wall time is higher than ordinary/receiver-clone here despite
small returned logical writes; no general speedup claim follows. Full SOL
comparisons still include original/new upstream, compiler/clone/semantics/workers,
required sizes and workloads, same/cross-volume/network/non-APFS, cache state and
available device classes. Primary logical reads/returned writes/network counters
and partial phase intervals are not complete physical IO or total commit time.
